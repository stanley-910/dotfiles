# 6-Week LeetCode Progression

Pacing: ~2 problems/weekday, 1/weekend (~11/week). Quality of understanding over
raw count. When stuck, hints come only after real effort (see SKILL.md). Always
state time/space complexity. Problems are listed in climbing order within each week.

## Week 1 — Arrays, Strings, Two Pointers
Warm-up: 1 (Two Sum), 415 (Add Strings), 832 (Flipping an Image),
905 (Sort Array By Parity), 443 (String Compression)
Core: 53 (Maximum Subarray), 56 (Merge Intervals), 54 (Spiral Matrix),
63 (Unique Paths II), 15 (3Sum), 2 (Add Two Numbers)

## Week 2 — Sliding Window + Hashing
Pattern: 438 (Find All Anagrams), 128 (Longest Consecutive Sequence),
539 (Minimum Time Difference), 766 (Toeplitz Matrix)
Climbing: 845 (Longest Mountain), 849 (Maximize Distance to Closest Person),
1438 (Longest Continuous Subarray w/ Abs Diff ≤ Limit), 981 (Time Based KV Store),
1146 (Snapshot Array), 1865 (Finding Pairs With a Certain Sum),
3043 (Longest Common Prefix length), 3034 (Subarrays That Match a Pattern I)

## Week 3 — Trees, Graphs, BFS/DFS
Trees: 98 (Validate BST), 153 (Find Min in Rotated Sorted Array),
162 (Find Peak Element), 230 (Kth Smallest in BST), 742 (Closest Leaf in BT),
1650 (LCA of a Binary Tree III), 2096 (Step-By-Step Directions BT Node to Another)
Graphs/BFS: 210 (Course Schedule II), 721 (Accounts Merge),
632 (Smallest Range Covering K Lists), 1293 (Shortest Path w/ Obstacle Elimination),
1334 (City With Smallest Number of Neighbors at Threshold)

## Week 4 — Dynamic Programming
1D: 198 (House Robber), 213 (House Robber II), 931 (Minimum Falling Path Sum),
1814 (Count Nice Pairs)
2D: 72 (Edit Distance), 1143 (Longest Common Subsequence),
311 (Sparse Matrix Multiplication)

2009 (Min Ops to Make Array Continuous),
3165 (Max Sum of Subsequence w/ Non-adjacent Elements),

## Week 5 — System & Data-Structure Design (overlaps the implementation round)
Foundational: 146 (LRU Cache), 622 (Design Circular Queue),
359 (Logger Rate Limiter), 362 (Design Hit Counter)
Intermediate: 348 (Design Tic-Tac-Toe), 900 (RLE Iterator),
933 (Number of Recent Calls), 1244 (Design A Leaderboard), 981 (Time Based KV Store)
Advanced: 352 (Data Stream as Disjoint Intervals), 588 (In-Memory File System),
2276 (Count Integers in Intervals), 2296 (Design a Text Editor),
3276 (Select Cells in Grid With Maximum Score)

Note: for design problems, do a second clean-code pass (proper class/interface,
error handling, edge cases, what you'd unit-test) — this doubles as implementation-
round prep.
